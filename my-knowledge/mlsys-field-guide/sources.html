The source hierarchy is claim-shaped

No source sits at the top for every question. Select authority by the claim being made, then preserve its version and limitations.

algorithm authority

Primary paper or standard

Defines an equation, method, reported experiment, or shared security vocabulary. It does not prove this checkout matches it.

implementation authority

Code at a frozen commit

Shows what can be constructed or called at that revision. It does not prove a training job executed that path.

execution authority

Run artifacts

Immutable config, data manifest, seed, logs, hardware trace, checkpoints, and eval outputs establish what happened. Learner runs do not exist yet.

discovery aid

Transcript or personal note

Locates questions and explanations. Every factual claim must travel upward to an official source, paper, code anchor, or run artifact.

Inference timing caution

The generation module’s first-token timing is measured around its internal first forward pass. It is not end-to-end arrival-to-first-byte TTFT: queueing, tokenization, network transport, scheduler delay, and response serialization are outside that timer.

2025 and 2026 are different course snapshots

The official material here is Spring 2026; the transcript is Spring 2025. Lecture numbers, examples, assignments, and contemporary model claims must not be merged as if they came from one release.

Duplicated prose is a generation defect

notes/lec15.md repeats the “Training Data: Instruction Tuning Datasets” section. notes/lec07.md repeats its practical takeaways/TL;DR and contains a malformed errors.## TL;DR boundary. Repetition is not corroboration.

Currency once collided with MathJax

The pinned transcript commit d7d100e4 fixes dollar currency being parsed as math delimiters. Older HTML or copied excerpts may still contain broken inline equations; compare with the pinned source.

TPP is a ratio, not throughput

TPP = training tokens / parameter count. Name the denominator—total, non-embedding, or active parameters—especially for MoE. A checkpoint from one trajectory is not an independent scaling point; each point requires its own run.

alpha_f is not a Boolean

In the scheduler schema it is a floating terminal learning-rate fraction: η_min = η_initial × α_f. A handwritten question mark can mean “check this type”; resolve it from the schema instead of silently deleting it.

optim/scheduler.py

Tokenization is not embedding

A tokenizer deterministically maps normalized text or bytes to integer IDs under a pinned vocabulary and rules. An embedding is a trainable lookup from IDs to model vectors. The data pipeline crosses that boundary at [B,S].

RoPE rotates Q and K

Standard RoPE applies position-dependent paired rotations after Q/K projection—not to the token embedding table. Image-position schemes vary: the OLMo vision path inspected here is not Qwen-style M-RoPE.

Two z-losses must not be conflated

Router z-loss penalizes the squared router logsumexp to control logits. Load balance is a separate objective. The LM-head softmax z-loss has a different scope even when the mathematical motif looks similar.

“Auxiliary-loss-free” needs a footnote

DeepSeek-V3 removes the usual token-level auxiliary balancing objective, but uses per-expert routing bias and reports a complementary sequence-wise balance loss. The phrase does not mean “no balancing mechanism or related loss.”

A fingerprint is not automatically a security hash

The inspected NumPy document-source fingerprint is derived from source metadata such as paths and sizes, rather than hashing every file’s bytes. Treat it as reproducibility identity, not proof against tampering.

numpy_document_source.py

Assignments are not official solutions

The unofficial assignment pages are useful study guidance. They do not establish Stanford grading criteria, reference outputs, or endorsed solutions. Link claims back to the official course snapshot.

Promotion workflow: from note to report claim

A source becomes useful when its claim, version, implementation, experiment, and limitation can be inspected independently.

1 · question

Preserve the learner mark

Record the underline, blue dot, example algorithm, or question mark without converting uncertainty into a fact.

2 · ground

Find the defining source

Capture the exact equation, paper section, official lecture, terminology version, and scope.

3 · trace

Anchor executable behavior

Pin the code commit, config path, tensor shapes, defaults, and boundary where another repository takes over.

4 · execute

Produce run evidence

Save data manifest, tokenizer hash, seed, full config, environment, logs, profiler trace, checkpoints, eval outputs, failures, and costs.

Minimum transparent-report test

A reader should be able to distinguish model definition, parameter convention, data and mixture, scaling hypothesis, independent points and trials, token budget and TPP, optimizer and schedule, phase boundaries, eval selection/final gates, measured loss curves, inference workload and SLOs, hardware/parallelism, security controls, and released artifacts. Missing fields stay visibly missing.
