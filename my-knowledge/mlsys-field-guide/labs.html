02

Activation curves and equal-parameter FFNs

browser-local math measurement extension
Objective

Compare ReLU, GELU, and SiLU numerically, then compare a plain FFN with gated SwiGLU at equal leading-order parameter count.

Prerequisites

Elementwise functions and two/three linear projections.

Expected invariant

Plain FFN ≈ 2dh; gated FFN ≈ 3dhg; fair width uses hg≈2h/3. SwiGLU is a gated block, not a scalar activation curve.

Execution class

Curves and counts run here. Throughput and quality claims require matched training and kernel measurements.

Curve probe

Fair-comparison readout

Motivation is a hypothesis, not proof

Smooth nonzero negative outputs and multiplicative gating may improve optimization/expressivity. Only matched architecture, data, compute, and repeated trials can establish a model-quality advantage.

Evidence to save

Probe values at −1, 0, and 1; screenshot or numeric curve sample; plain/gated hidden widths and exact counts; matched-run requirements.

Exact trail

nn/feed_forward.py implements the gated OLMo FFN; OLMo config choices are silu or gelu_tanh. Read GLU Variants Improve Transformer and Llama 2. Guided extension: benchmark the built module; do not compare unmatched hidden widths.

browser-local math 2D/M-RoPE extension
Objective

Numerically verify (R(m)q)ᵀ(R(n)k)=qᵀR(n−m)k and allocate separate row/column rotations.

Prerequisites

2×2 rotation matrices, dot products, and token coordinates.

Expected invariant

The two 1D dots match within floating-point error. Image 2D axes encode spatial displacement; they are not “the two numbers inside one RoPE pair.”

Execution class

The identity runs here. OLMo-core has text RoPE; this checkout does not implement spatial 2D or multimodal M-RoPE.

04

MHA, GQA, and MQA KV-cache calculator

browser-local math engine measurement
Objective

Relate query/KV head topology to cached bytes per request.

Prerequisites

Q/K/V shapes, head dimension, bytes per scalar.

Expected invariant

Hq % Hkv = 0; cache bytes = 2·B·L·S·Hkv·dh·bytes. Changing Hkv changes cache, not the number of query heads.

Execution class

Ideal tensor bytes run here. Allocator blocks, paging, fragmentation, quantization, and prefix sharing require an engine trace.

Topology and workload

Cache readout

Evidence to save

Hq/Hkv/dh/L/S/B/dtype, topology label, ideal bytes, MHA baseline, savings ratio, and engine-specific measured allocated/resident bytes.

Exact trail

nn/attention/__init__.py defines query and KV projections; attention/kv_cache.py stores (B,S,Hkv,dh) K and V. Read GQA and PagedAttention.

05

MoE routing, collapse, balancing, and z-loss

browser-local math distributed extension
Objective

Route four tokens, compute expert fractions/probabilities, verify load-balance and router z-loss, then induce and counter collapse.

Prerequisites

Softmax, top-1 selection, frequency vectors, log-sum-exp.

Expected invariant

Lbal=NΣe fₑPₑ uses hard assignment fractions and mean soft probabilities; Lz=mean(logsumexp(logits)²) limits logit scale. They address different failures.

Execution class

Single-batch math runs here. Capacity drops, all-to-all, expert parallelism, gradients, and convergence need an OLMo run.

Router controls

top-1 toy batch

Loss verification

DeepSeek-V3 nuance

Its main device-level balancing uses an auxiliary-loss-free selection bias, yet it retains a tiny sequence-wise auxiliary loss. “Aux-loss-free” does not mean no routing controls or no auxiliary term anywhere.

Evidence to save

Raw logits, selection bias, probabilities, chosen experts, f and P vectors, unscaled/scaled Lbal and Lz, capacity/drop policy, and expert-parallel topology.

Exact trail

nn/moe/router.py routes and can apply load-balancing bias; nn/moe/loss.py defines both losses. Guided parity: pytest -v src/test/nn/moe/router_test.py. Read Switch Transformer, DeepSeekMoE, and DeepSeek-V3.

Scaling point, repeated trials, fit, and uncertainty

synthetic browser fit training trials
Objective

Make every scaling dot a set of trials, fit an optimum, and expose uncertainty rather than selecting one lucky run.

Prerequisites

Means, sample standard error, log model size, quadratic least squares.

Expected invariant

One trial has undefined sample SE; repeated trials preserve individual rows. A fitted optimum is a prediction with a valid range, not an executed model.

Execution class

All losses are deterministic synthetic teaching data. Real points require independent runs, immutable logs, and a held-out prediction scale.

Inference prefill/decode profile

compute-only model serving trace
Objective

Separate prefill from autoregressive decode and distinguish compute time from end-to-end serving latency.

Prerequisites

Prompt/output tokens, throughput, TTFT, TPOT, KV-cache bytes.

Expected invariant

Prefill processes P tokens together; decode adds one token/sequence/step. End-to-end TTFT includes arrival, queue, scheduling, transfer, and compute—not just model forward time.

Execution class

This is a deterministic arithmetic model. Continuous batching, paging, prefix caching, quantization, and goodput require an engine/workload trace.
