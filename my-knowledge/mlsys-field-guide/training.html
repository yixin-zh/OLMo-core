Accounting rule

Always distinguish unique eligible tokens, tokens seen, padding, and loss-bearing tokens. “Training tokens” without scope is ambiguous.

A recipe is a hypothesis. A run is evidence.

Trace raw sources into token batches, choose scaling points with repeated trials, freeze the optimizer and schedule, cross explicit phase gates, and keep selection evaluation separate from untouched final claims.

Core distinction

A config records intended behavior. Exact data order, optimizer/dataloader state, logs, discarded trials, restarts, checkpoints, and hashes record execution.

Feasibility and fingerprint warning

Composable mixtures can reject a target whose source exposure exceeds its cap; a normalized request is not automatically feasible. The legacy OLMo NumPy source fingerprint uses basenames and sizes, not content bytes. A transparent release needs separate content digests. Inspect the fingerprint and composable sources.

What the shorthand hides

Ctrain≈6Nactive,nonembDseen is a first-order active-path proxy. Attention, routing, and communication need measured or model-specific FLOPs. D/Ntotal is a separate capacity ratio. Chinchilla’s roughly 20 TPP is an empirical regime, not a universal constant.

OLMo-core boundary

model_ladder can configure sizes/runs and collect metrics. It does not fit scaling-law exponents, automate uncertainty, or supply multiple seeds per point.

Concrete OLMo caveat · baseline 1e03ad1

EvaluatorCallback supports startup, finish, step interval, and fixed-step evaluation. Both 7B stage-1 scripts attach LM and downstream evaluators every 10,000 steps; the 32B pretrain script uses 1,000. The 7B/32B midtrain and long-context scripts attach no evaluator callback. This establishes in-loop callback configuration—not an untouched final evaluation or a completed eval artifact.
